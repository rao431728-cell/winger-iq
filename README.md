# WINGER IQ

WINGER IQ is an interactive tactical decision-training application for wide players and attacking midfielders.

## Features

- Positioning, scanning, receiving, 1v1, pressing, transition and final-third modules
- Scenario-specific tactical visuals
- Decision questions with explanations
- Match-round simulation
- Ten-minute daily training session generator
- Local progress, accuracy and topic ratings
- Keyboard- and browser-friendly static architecture

## Technology

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- localStorage for progress
- SVG tactical diagrams
- Optional WebMCP tools for reading progress and opening modules

## Run locally

Serve the `dist` directory with any static web server, then open `index.html`.

## Verification

The JavaScript parses successfully and all required HTML/CSS files are present.
